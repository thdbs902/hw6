1 · Cost

Caching cut the bill by 85.5%

The shop handbook (about 10,058 tokens) goes to the model on every call. When the start of the prompt is identical each time, the model reads it from a cache at a tenth of the price. I ran the agent on all 12 practice documents both ways.

Cost per document

30 days at 1,000 documents a day

Where the input tokens went (12 documents, 24 model calls each)

  • Read from cache ($0.01/1M)
  • Written to cache ($0.125/1M)
  • Plain input ($0.10/1M)

It really worked

Without cache: 0 of 24 calls used cached tokens. With cache: 23 of 24 did. Every call was a fresh model call.

vs my estimate

I estimated $0.001006 per call without cache and $0.000101 with it. The real cost per document is higher ($0.002758 and $0.000400) because the agent makes 2 calls per document and sends the handbook both times.

Surprise

"Without cache" cost more than plain input. The API charged $0.125 per million tokens to store 256,819 tokens that were never reused.

Code layer

Reads each document the way a person sees it, and throws away invisible text: tiny or white fonts, hidden boxes, off-page text, comments.

Design layer

The AI only reads off five facts. Plain code applies the handbook rules. Email and payment tools need a human sign-off.

Prompt layer

Rules that say the document is outside data, not orders, and to ignore side notes that "correct" the price or terms.

5 · Recommendation

To the store manager: yes, turn DD on, with a person in the loop

About $8.88 a month for 1,000 vendor documents a day.

  • Why yes: with all defenses on, DD got every practice decision right, blocked every hidden attack, and on 10 new exam documents never sent an email or approved a payment.
  • What it costs: $0.000296 per document × 30,000 documents = $8.88 a month with caching. If the cache ever stopped working, the worst case is about $83.65 a month. That is still small.
  • How to run it safely: keep payments and emails behind a human sign-off, have the buyer approve every "buy", and send any quote with hidden text removed to a person for a second look.
  • Start small: run it next to the buyer for two weeks and compare answers before relying on it.
